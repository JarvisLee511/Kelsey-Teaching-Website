# 周老師的學習樂園

給小朋友的教學遊戲網站 —— 四個遊戲，用玩的方式學食物分類、物理現象和越南文化。無登入、無廣告、手機可玩。

**🌐 <https://jarvislee511.github.io/Kelsey-Teaching-Website/>**

---

## 四個遊戲

| 遊戲 | 學什麼 | 玩法 |
|---|---|---|
| **飲食彩虹大冒險** | 六大類食物 | 把食物拖到正確的分類：飯麵類、肉蛋豆、蔬菜、水果、牛奶類、油脂堅果。分關卡、有連擊、有時間限制 |
| **消消樂** | 反應與觀察 | 7×N 格盤面消除同類，60 秒計時、記分並保留最高分 |
| **生活物理小問答** | 生活中的物理現象 | 選擇題，答錯會解釋為什麼 |
| **認識越南小問答** | 越南文化與生活 | 選擇題，附提示 |

## 設計上刻意的地方

- **答錯不扣分、不責備。** 過不了關的畫面寫的是「沒關係！再試一次，你一定做得到！💪」，不是「失敗」。時間到了也一樣。
- **每題都給解釋。** 物理和越南文化的問答答完會說明原因，不只是對或錯。
- **關卡制 + 連擊 + 最高分** 讓小朋友有理由再玩一次，但沒有排行榜、沒有和別人比較。
- **全中文、大字、大按鈕**，手機直接開就能玩。

## 技術

單一 `index.html`，約 2,300 行，96 KB —— HTML、CSS、JavaScript 全部內嵌。

沒有框架、沒有建置步驟、沒有外部依賴。整個網站就是一個檔案，所以：

- 老師可以直接下載一份帶去沒有網路的教室
- 要改題目就直接改檔案，不用重新編譯或部署工具鍊

## 修改題目

題庫是 `index.html` 裡的陣列，找 `game-physics` 和 `game-vietnam` 相關的題目資料就能直接加減題目。食物分類遊戲的品項也在同一個檔案裡。

## 部署

GitHub Pages，預設分支 root 路徑。push 到 `main` 就更新。
